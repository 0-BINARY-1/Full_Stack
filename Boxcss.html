Box Model

The box model is a fundamental concept in web design and development that describes how elements are rendered on a web page. It consists of four main components:

  1. MARGIN
  2. BORDER
  3. PADDING
  4. CONTENT
            Note: We don't need to specify all the margin for top, right, bottom and left. We can specify the margin in one line.
            For example, if we want to set the margin as 10px, 20px the these margins will
            apply as top and bottom margin = 20px and left and right margin = 10px.
