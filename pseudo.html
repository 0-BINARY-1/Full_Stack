Pseudo-elements to allow styling a specific part of an element.

        pseudo-classes
        hover: to add effects when the mouse is hovered over the respective object. 
        active: adds effects when the element is being activated, such as clicking.
        focus: important for form inputs to highlight the area where the input is 
               being done.
        visited: It specify/indicate that the user has already visited.

        first-child: to apply css to the first element of the list.
        last-child: to apply css to the last element of the list.
        nth-child(n): n=2,3,4,.... to apply the css to specified position element.
        nth-child(odd): to edit the odd position element. Suitable to format table.
        nth-child(even): to edit the even position elements. Important during table formatting.
        
        pseudo-elements
        ::first-letter: to apply css to the first letter of the specified html element content.
        ::first-line: to apply the css to the first line of the content.
        ::before: to place generated content before the content of html elements.
        ::after: to place generated content after the content of html elements.

        
All pseudo elements
