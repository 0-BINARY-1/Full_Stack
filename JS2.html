Types of variables

It is a named container used to store the data in a program.

Syntax:

variable_keyword   variable name = variable data
    
        1. var: old and obsolute method
        2. let: new method in which we can reassign the value to same variable.
        3. const: new method in which we can define constatn variables.

Data Types

  1. String
  2. Number
  3. Boolean
  4. Undefined
  5. Null
  6. Object
  7. Symbol

Checking the data type

Syntax:

typeof variable_name

Printing the type:

console.log(typeof variable_name);
