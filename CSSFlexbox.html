CSS Flexbox Intro

This is CSS layout system used to arrange elements in rows and columns. It is useful for:

  1. Navigation bars
  2. Cards
  3. Menus
  4. Aligning content
  5. Centering elements
  6. Creating responsive layouts

Normally, HTML elements appear one after another. We can control how elements are arranged.

Basic FlexBox Example

We can set flex direction like row, column, reverse row and column.

            A. flex-Direction: Row, Column, Reverse-Row, Reverse-column 
            B. justify-content: controls the arrangement along the main axis. So item inside any container
            udmoves to center of that container  horizontally.

            Common values of justify content:
                1. justify-content: flex-start;
                2. justify-content: flex-end;
                3. justify-content: center;
                4. justify-content: space-between;
                5. justify-content: space-around;
                6. justify-content: space-evenly;
            C. align-items: This controls alignment on the cross axis.
            D. gap: Instead of margin we can use gap between flex items.
