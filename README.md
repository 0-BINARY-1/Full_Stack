# About the project

# Major points:
  
### Basic HTML elements are:  

| Element    | Purpose                                 |
| ---------- | --------------------------------------- |
| `<html>`   | Starting of the html document                       |
| `<head>`  | For defining the extra information about the HTML document  |
| `<title>`  | Title of the HTML document          |
| `<body>` | Main content area             |
| `<h1>`     | Largest heading |
| `<h6>`      | Smallest heading   |
| `<ol>`   | Ordered list                       |
| `<ul>`  | Unordered list   |
| `<li>`  | For making the list        |
| `<a>` | For providing the hyperlink or url which is clickable and direct us to the clicked link        |
| `<img>`     | Adding image|
| `<p>`      | Writing paragraph  |
| `<br>`   | Adds line break  |
| `<strong>`  | give importance to the content inside this HTML element    |
| `<em>`  | Emphasise the content inside this HTML element           |
| `<b>` | bold |
| `<i>`     | itallic |
| `href`      | Attribute which specify the hyperlink reference   |
| `src`     | Attribute which tells the source of the content |
| `alt`      |  Attrubute to display alternet content if image, video, etc failed to load    |


### Some of the important HTML elements related to html form are:  

| Element    | Purpose                                 |
| ---------- | --------------------------------------- |
| `<form>`   | Creates a form                          |
| `<label>`  | Gives a name/description to an input    |
| `<input>`  | Allows the user to enter data           |
| `<button>` | Creates a clickable button              |
| `type`     | Defines what kind of input/button it is |
| `id`       | Gives an element a unique identifier    |

### Different types of forms are:

- Login form
- Registration forms
- Contact forms
- Search boxes
- Feedback forms

### Important terms related to html table:  

`<th>` = Table head  
`<tr>` = Table row  
`<td>` = Table data  


### Important semantic elements:  

| Element     | Purpose                      |
| ----------- | ---------------------------- |
| `<header>`  | Top/header section           |
| `<nav>`     | Navigation links             |
| `<main>`    | Main content                 |
| `<section>` | A section of related content |
| `<article>` | Independent piece of content like blog |
| `<aside>`   | Related/side content like info about author of the blog.       |
| `<footer>`  | Bottom/footer section        |
  

Note:  

We use `#` as shown:  href="#about". This `#` means: Go to the element whose `id` is `about`.
So we have to have a section with `id` = `about`, like shown below:  
`<section id="about">`  

We include all the sections inside the `<main>`, as shown below:
```
<main>   
    <section id="about">  
        .......  
    </section>  
    <section id="skills>  
        .......  
    </section>  
</main>
```
